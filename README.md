## 📖 项目简介

**Valorant Sensitivity Generator** 是一款纯前端、单文件 HTML 的灵敏度推荐工具。它通过一组内嵌的瞄准测试（目标触碰即命中，无需点击）采集你的反应速度、定位精度、追踪稳定性和微操能力，结合你的鼠标 DPI、操作流派（手臂流/手腕流）和游戏位置偏好，计算出当前版本无畏契约可直接使用的灵敏度数值。

生成的数值直接对应无畏契约设置中的 **"灵敏度 → 瞄准灵敏度"** 字段，范围严格控制在游戏允许的 `0.1 – 10.0` 区间内，保留两位小数，复制后粘贴即可生效。

## ✨ 核心特性

| 模块 | 说明 |
|------|------|
| 🎯 **Aimlabs 风格反应测试** | 多目标随机刷新，鼠标**碰到即命中**，无需点击；测量反应时间与基础命中率 |
| 📈 **追踪测试 (Tracking)** | 跟随匀速移动目标，统计准星与目标的偏差率，评估跟枪能力 |
| 🎯 **定位测试 (Flick)** | 大距离快速甩枪定位，测量转身速度与过冲/欠冲 |
| 🔍 **微调测试 (Micro-adjust)** | 小范围精细瞄准，评估微操稳定性与手抖动幅度 |
| ⏱️ **精准倒计时** | 使用 `requestAnimationFrame` 驱动，30 秒倒计时流畅不卡顿，结束自动出结果 |
| 🔫 **游戏内准星** | 测试时隐藏系统光标，替换为无畏契约风格十字准星 |
| 🧮 **灵敏度推荐算法** | 综合 4 项测试得分 + DPI + 流派 + 位置偏好，输出游戏内灵敏度 |
| 📊 **数据可视化** | ECharts 雷达图展示能力维度，进度条展示单项评分 |
| 📋 **一键复制** | 一键复制灵敏度数值，直接粘贴到游戏设置中 |
| 🌐 **纯前端单文件** | 无后端、无依赖、无安装，双击 HTML 即可运行 |

## 🎮 使用流程

```
┌─────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  1. 填写信息  │ -> │  2. 完成 4 项  │ -> │  3. 查看结果  │ -> │  4. 复制灵敏度 │
│  DPI / 流派  │    │  瞄准测试      │    │  雷达图+评分  │    │  粘贴进游戏   │
└─────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

### 第一步：填写个人设置
- **鼠标 DPI**：你鼠标的当前 DPI（常见 400 / 800 / 1600）
- **操作流派**：手臂流 / 手腕流 / 混合流
- **常用位置**：决斗 / 哨位 / 控场 / 先锋
- **当前灵敏度**（可选）：游戏内现有灵敏度，用于对比

### 第二步：完成 4 项测试
每项测试时长 **30 秒**，鼠标碰到目标即算命中：

1. **反应测试** — 目标随机出现，碰到即消，测反应
2. **追踪测试** — 目标匀速移动，准星持续贴住目标算分
3. **定位测试** — 目标在屏幕两端交替出现，测甩枪
4. **微调测试** — 小目标密集出现，测精细控制

> ⚠️ 测试过程中系统鼠标会被隐藏，替换为游戏风格十字准星，这是正常现象。

### 第三步：查看推荐结果
- **推荐灵敏度**：游戏内"瞄准灵敏度"数值（保留两位小数）
- **eDPI**：`DPI × 游戏灵敏度`，用于跨设备对比
- **cm/360°**：转身一圈需要移动的物理距离
- **调整建议**：偏高 / 适中 / 偏低
- **能力雷达图**：反应、追踪、定位、微调四维评分

### 第四步：应用到游戏
1. 打开无畏契约 → **设置 (Settings)**
2. 进入 **一般 (General)** → **灵敏度 (Sensitivity)**
3. 在 **瞄准灵敏度 (Aim Sensitivity)** 中粘贴复制的数值
4. 确认 **瞄准镜灵敏度倍数 (Scoped Sensitivity Multiplier)** 保持 `1.0`（默认）

## 🧠 灵敏度计算逻辑简介

工具综合以下维度计算推荐值：

| 维度 | 权重影响 |
|------|---------|
| 反应测试命中率 & 平均反应时间 | 基础精度分 |
| 追踪测试准星贴合率 | 跟枪能力 → 影响纵向灵敏度 |
| 定位测试过冲/欠冲比 | 甩枪稳定性 → 过高则建议降灵敏度 |
| 微调测试抖动幅度 | 微操精度 → 抖动大建议降低灵敏度 |
| DPI | 换算 eDPI 与 cm/360° |
| 手臂流 / 手腕流 | 手臂流推荐更低灵敏度（更大移动空间） |
| 位置偏好 | 决斗位偏高灵活动态，哨位/架点位偏低更稳 |

> 计算结果为推荐值，实际手感仍建议在游戏训练场中微调 ±5% 左右找到最舒服的感觉。

## 🛠 技术栈

- **HTML5 Canvas** — 所有瞄准测试均基于 Canvas 渲染
- **Vanilla JavaScript (ES6+)** — 无框架、无依赖
- **`requestAnimationFrame`** — 驱动测试循环与倒计时，保证流畅不卡顿
- **ECharts** — 结果页雷达图与评分可视化
- **CSS3** — 无畏契约品牌色 `#FF4655` + 深色 HUD 风格
